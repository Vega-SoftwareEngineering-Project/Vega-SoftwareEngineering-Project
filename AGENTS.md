# Инструкции для ИИ-агента

## Назначение проекта

Это небольшой учебный проект на C++17. Программа складывает два целых числа.

## Структура

- `main.cpp` — консольное приложение.
- `include/` — заголовочные файлы.
- `lib/` — реализации функций.
- `tests/` — unit-тесты GoogleTest.
- `benchmark/` — бенчмарк Google Benchmark.
- `CMakeLists.txt` — конфигурация сборки.
- `.github/workflows/ci.yml` — CI/CD на GitHub Actions.
- `Doxyfile` — конфигурация Doxygen.

## Команды

Сборка:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

Запуск тестов:

```bash
ctest --test-dir build --output-on-failure
```

Запуск бенчмарка:

```bash
./build/benchmark_add --benchmark_min_time=0.1s
```

Запуск программы:

```bash
./build/main 12 13
```

## Правила

- Используй C++17.
- Используй отступы в четыре пробела.
- Объявления размещай в `include/`, реализации — в `lib/`.
- При изменении поведения добавляй или обновляй тесты.
- Перед завершением задачи собирай проект и запускай тесты.
- Если изменён код бенчмарка или измеряемой функции, запускай бенчмарк.
- Не меняй CI/CD и версии зависимостей без прямого запроса.
- Не добавляй функциональность и зависимости сверх требований задачи.
